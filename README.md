# Всегда рядом

Первый устанавливаемый прототип Android-приложения с тёмным интерфейсом и неоново-зелёными акцентами.

## Уже реализовано
- Экран приложения «Всегда рядом».
- Запрос разрешения на геолокацию.
- Получение и отображение координат текущего устройства.

## Пока не реализовано
- Регистрация и подключение друзей.
- Обмен геопозицией между устройствами и сервер.
- Фоновое обновление каждые 5 минут.
- Интеграция с 2ГИС.

Геопозиция других людей должна передаваться только с их явного согласия.

## Сборка APK
GitHub Actions собирает debug APK при push в `main`. Открой вкладку Actions, выбери успешный запуск и скачай артефакт `always-nearby-debug-apk`.
